# Placing the story NPCs

The nine story NPCs are ready-made **Easy NPC presets** in the pack (`kubejs/data/tt/easy_npc/preset/`, generated by
`tools/gen_npcs.py` from the scripts in `design/npcs/`). Each one already has its name, colour, skin and every
conversation from the scripts. Right-click an NPC to get a menu with one button per conversation (labelled by chapter)
plus **Chat**, which shows its ambient lines.

## Placing one (cheats on, stand where it should go)

```
/easy_npc preset import_new data tt:easy_npc/preset/humanoid_slim/maera.npc.snbt ~ ~ ~
```

| NPC | Preset | Where (from the scripts) |
|---|---|---|
| Elder Maera | `humanoid_slim/maera` | Refugee camp in Ch1, then the Emberhold Town Hall |
| Doran | `humanoid/doran` | Emberhold forge (Blacksmith hut) |
| Captain Rhosk | `humanoid/rhosk` | Emberhold walls / guard tower |
| Pell | `humanoid/pell` | Scrap tent at the first ruin, later a Create workshop in Emberhold |
| Tamsin Rootwarden | `humanoid_slim/tamsin` | Old oak at the edge of the nearest forest (never inside the colony) |
| Ilsabet | `humanoid_slim/ilsabet` | Conclave tower in Emberhold (Town stage) |
| The Stranger | `humanoid/stranger` | Emberhold market from Ch6 (remove after Ch8) |
| Wren | `humanoid_slim/wren` | Emberhold gate |
| Archivist Sol | `humanoid/sol` | Emberhold library (Town stage) |

Tab completion after `data` lists all of them. In the Easy NPC editor (sneak + right-click with the wand) you can then
change the skin, pose or position; conversations live under *Dialog*.

## Notes
- Talking never gives items: rewards stay in the quest book. The quests that say "Talk to …" are still ticked by hand.
- To change a line, edit `design/npcs/*.md` and rebuild; placed NPCs keep their old dialog until re-imported.
- Not yet: trades (the scripts list them; set them in the editor's *Trading* tab), quest-aware menus.
